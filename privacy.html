Privacy Policy

Effective November 2026

This policy applies to the Hermes personal automation agent and its OAuth client. There is exactly one user: the developer and owner, WiggityWack0.

What data the agent accesses

With the owner's explicit consent, the agent accesses the owner's own Google account via Google APIs:

  • Gmail — read, search, and send email (read-only, modify, and send scopes).
  • Google Calendar — read and create calendar events.
  • Google Drive, Docs, and Sheets — search, read, create, and edit the owner's files.
  • Google Contacts — read-only contact lookup.

What happens to that data

  • All processing happens on the owner's own computer. Data is used only to serve the owner's own requests (e.g., summarizing calendar events, drafting replies, finding a document).
  • The agent does not sell, share, publish, or transfer any Google account data to third parties.
  • Conversation records and token files are stored locally on the owner's machine.
  • OAuth tokens can be revoked by the owner at any time (Google account security settings or the agent itself); revoking access immediately ends all API access.
  • When the agent is retired, tokens and locally cached copies of Google data are deleted.

Cookies and tracking

These documentation pages set no cookies and collect no analytics or tracking data.
