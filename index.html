Hermes Personal Agent

This page documents a personal automation agent called Hermes, operated by Sid Haynes for his own use on a single Google account.

The agent uses an OAuth 2.0 client to access that one Google account's Gmail, Calendar, Drive, Docs, Sheets, and Contacts (read-only) on the owner's behalf — for tasks such as calendar summaries, email triage, document lookups, and personal reminders. It is not a public application, is not distributed, and is not available to any other users.

The agent runs locally on the owner's own computer. The owner is the developer, the only user, and the only person whose data the app touches.
